# 🖱️ Finger Mouse Control (AI Gesture System)

A real-time **AI-powered finger tracking mouse controller** using webcam.  
Control your computer using hand gestures instead of a physical mouse.

Built with OpenCV + MediaPipe + PyAutoGUI.

---

## 🚀 Features

- 🖱️ Move cursor using index finger
- 👆 Left click → thumb + index pinch
- ✊ Right click → fist hold
- 📜 Scroll → two-finger movement
- 🎯 Smooth cursor movement (anti-jitter)
- ⚡ Real-time webcam processing

---

## 🧠 Gesture Controls

| Action | Gesture |
|--------|--------|
| Move cursor | Index finger |
| Left click | Thumb + Index pinch |
| Right click | Fist (all fingers closed) |
| Scroll | Index + Middle finger movement |
